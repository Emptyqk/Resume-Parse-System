# 智能简历解析系统

## 系统概述

智能简历解析系统是一款基于.NET 8.0 Windows Forms开发的桌面应用程序，旨在为用户提供高效的简历管理解决方案。该系统支持导入、解析、管理和查重Word与PDF格式的简历文件，能够自动提取关键信息并进行结构化存储，同时集成AI功能提供智能评估和匹配服务。

## 主要功能

### 1. 简历导入与管理

- **支持格式**：Word文档(.doc, .docx)和PDF文档(.pdf)
- **导入方式**：
  - 点击按钮选择文件导入
  - 拖拽文件到导入区域
- **重复处理**：自动检测同名文件，可选择是否替换
- **批量导入**：支持一次性导入多份简历
- **目录管理**：可创建和管理简历目录，方便分类存储

### 2. 简历解析与结构化

系统能够自动从简历中提取以下关键信息：

- **基本信息**：姓名、性别、出生日期、地址
- **联系方式**：手机号码、邮箱、身份证号
- **教育背景**：最高学历学校、专业、第一学历信息
- **工作经历**：公司、岗位、职责等
- **技能专长**：个人职业技能

### 3. 简历检索

- **多条件查询**：
  - 按导入日期查询
  - 按文件名称查询
  - 按目录分类查询
- **详情查看**：点击搜索结果可查看简历详细信息，包括完整的工作经历和技能列表

### 4. 简历查重

- **多维度查重**：支持按姓名、手机号码、邮箱、身份证号进行查重
- **结果展示**：以分组形式显示重复简历
- **导出功能**：可将查重结果导出为TXT或Word文件

### 5. 数据格式转换

- **多格式支持**：
  - 将简历数据导出为JSON格式
  - 将简历数据导出为CSV格式，便于Excel处理
  - 将简历数据导出为Word文档
- **格式互转**：支持JSON、CSV、Word格式之间的相互转换

### 6. 数据分析与报告

- **数据统计**：自动分析简历库中的性别分布、年龄分布、学历分布和技能分布
- **趋势分析**：展示简历导入的时间趋势
- **报告生成**：生成详细的数据分析报告并导出为Word文档

### 7. AI智能功能

- **智能简历评估**：
  - 基于内容自动评分（0-100分）
  - 生成总体评价、核心优势和潜在风险分析
  - 提供面试问题建议和简历改进建议
- **语义搜索与匹配**：
  - 支持自然语言搜索，理解用户意图
  - 上传岗位描述后，自动匹配最合适的简历并排序
- **简历总结**：自动生成简历核心内容摘要，快速了解候选人情况

## 安装与运行

### 系统要求

- Windows 10/11 操作系统
- .NET 8.0 Runtime
- Microsoft Office（可选，用于Word文档解析）
- 网络连接（可选，用于AI功能）

### 编译运行

1. 克隆或下载项目代码
2. 打开项目文件夹
3. 运行以下命令编译项目：

   ```bash
   dotnet build
   ```

4. 运行程序：

   ```bash
   dotnet run
   ```

### 生成可执行文件

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

生成的可执行文件将位于 `bin/Release/net8.0-windows/win-x64/publish/` 目录下。

## 使用说明

### 1. 导入简历

1. 点击左侧"简历导入"按钮
2. 在右侧面板中点击"选择文件导入"按钮或直接拖拽文件
3. 选择Word或PDF格式的简历文件
4. 系统自动解析并导入简历
5. 可选择将简历归类到特定目录

### 2. 检索简历

1. 点击左侧"简历检索"按钮
2. 选择搜索类型（按导入日期、按文件名或按目录）
3. 输入搜索关键词（可选）
4. 点击"搜索"按钮查看结果
5. 点击搜索结果查看详细信息

### 3. 查重功能

1. 点击左侧"简历查重"按钮
2. 选择查重字段（姓名、手机号、邮箱、身份证号）
3. 点击"开始查重"按钮
4. 查看查重结果
5. 可选择导出查重结果为TXT或Word格式

### 4. 数据导出与转换

1. **导出简历**：
   - 在检索页面中搜索到需要的简历
   - 选择导出格式（JSON/CSV/Word）
   - 点击"导出"按钮并选择保存路径

2. **格式转换**：
   - 点击左侧"格式转换"按钮
   - 选择源格式和目标格式
   - 选择要转换的文件
   - 选择保存路径完成转换

### 5. 数据分析

1. 点击左侧"数据分析"按钮
2. 点击"生成报告"按钮
3. 选择报告保存路径
4. 系统将生成包含性别、年龄、学历和技能分布的详细报告

### 6. AI智能评估

1. 点击左侧"AI评估"按钮
2. 在简历列表中选择需要评估的简历
3. 点击"生成评估"按钮
4. 查看AI生成的评估报告，包括总体评价、核心优势、潜在风险和改进建议

### 7. 岗位匹配

1. 点击左侧"岗位匹配"按钮
2. 输入或粘贴岗位描述
3. 选择匹配范围（全部简历或当前搜索结果）
4. 点击"开始匹配"按钮
5. 查看按匹配度排序的结果列表

## 数据存储

系统使用JSON文件格式存储数据，数据文件保存在用户的应用数据目录中：

- 简历数据：`%APPDATA%\智能简历解析系统\resumes.json`
- 目录数据：`%APPDATA%\智能简历解析系统\directories.json`
- 评估记录：`%APPDATA%\智能简历解析系统\review_notes.json`

## AI服务配置

系统支持两种AI服务模式：

- **云端模式**：使用Azure OpenAI服务（需要网络连接和API密钥）
- **本地模式**：使用本地部署的AI模型（需额外安装和配置）

配置方法：在系统环境变量中设置：
- `QWEN_API_KEY`：API密钥（必需）
- `AI_BASE_URL`：API基础地址（可选）
- `AI_MODEL`：使用的模型名称（可选，我们使用的Qwen3）

## 注意事项

1. **文件格式**：目前支持Word(.doc, .docx)和PDF格式的简历文件
2. **解析精度**：简历解析的准确性取决于文档格式的规范性
3. **Office依赖**：Word文档解析需要安装Microsoft Office
4. **数据备份**：建议定期备份数据文件以防丢失
5. **文件权限**：确保程序有读取源文件和写入数据目录的权限
6. **AI功能**：首次使用AI功能需要配置API密钥，且部分功能需要网络连接

## 故障排除

### 常见问题

1. **无法解析Word文档**：检查是否安装了Microsoft Office，或尝试使用PDF格式
2. **无法解析PDF文档**：检查PDF文件是否损坏或加密
3. **导入失败**：检查文件格式是否正确，文件是否被其他程序占用
4. **数据丢失**：检查应用数据目录的权限设置，确保程序有写入权限
5. **AI功能无法使用**：检查API密钥是否正确配置，网络连接是否正常

### 技术支持

如遇到技术问题，请检查：

1. .NET 8.0 Runtime是否正确安装
2. 依赖库是否正确安装
3. 系统权限是否充足
4. 文件路径是否有效
5. 网络连接是否正常（针对AI功能）
